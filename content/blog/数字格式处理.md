在前端的数据展示中，必然涉及到很多的数字处理内容，例如小数位数的处理，百分数转化，货币金额的千分位分割符等，甚至是以上多种格式的组合。通常我们构建自己的数字格式化方法，内容相对繁琐，特别是涉及到一些国际化的问题时，复杂度就会陡然上升。也可以直接使用成熟的包来完成任务，但是往往发现需要多个包进行方法组合才能完成最终需求。实际上大多数浏览器支持**Intl.NumberFormat**构造函数，以方便快速进行数据处理。



## 单纯的数字
Intl.NumberFormat构造函数实例化时接受两个参数，第一个是地区编号，locale是BCP 47的语言编号或者Intl.Locale的实例的字符串，用以设置区域。而第二个参数options则是一些配置选项对象。其中style代表需要处理成的目标数据格式。这里我们设置decimal(也是默认值)。然后研究一些和数字有关的配置选项。请注意，本质上JS是不区分"整数"和"浮点数"的，但是数字格式展示时往往涉及到展示成"整数"还是"浮点数"的问题，因此在后续进行整数和小数(浮点数)的讨论时，整数表示不带小数部分的浮点数。



### minimumIntegerDigits
该属性控制整数部分的最小位数。如果整数部分位数小于该配置，则会向前(或者向左)填充0，以便达到指定长度。默认值是1。

```javascript
const num = 2024.0117
//设置minimumIntegerDigits为6
const formatter = Intl.NumberFormat('en-US', { style: 'decimal', minimumIntegerDigits: 6 })
formatter.format(num)  // '002,024.012'
```

可以看到输出了字符串，其有三个特质：

1. 添加了千分位符','以区分数位，这是因为设置了区域为en-US，以该区域数据进行输出时，会自动添加千位分割符。
2. 因为配置了minimumIntegerDigits为6，而num整数部分只有2024，所以用0向左补齐，整数部分变为'002,024'。
3. 小数四舍五入到了三位，这是因为默认配置引起的，后面会提到。



所以综上，minimumIntegerDigits作用就是控制整数部分的格式化内容，需要注意的是，该参数有限制，需要为整数，且值为1到21。



### minimumFractionDigits
该属性控制小数部分的最小位数。纯数字和百分比情况下默认值是0货币格式会参考货币代码表给出的单位标准，如果没有的话默认为2。如果小数部分位数小于该配置，则会末尾（向右）填充0，以便达到指定长度。

```javascript
const num = 2024.0117
//设置minimumFractionDigits为6
const formatter = Intl.NumberFormat('en-US', { style: 'decimal', minimumFractionDigits: 6 })
formatter.format(num)  // '2,024.011700'
```

可以看到最终给出的结果小数位数变成了6位，这个配置和上面提到的整数补位相关的配置非常相似。注意，这里的参数也有限制，需要为整数，值为0到20。



### maximumFractionDigits
该属性控制使用的最大小数位数，不过因为会有minimumFractionDigits也可以控制小数位数，所以二者配置有可能冲突，因此在两个配置起冲突的时候，以二者中较大值为准。

```javascript
const num = 2024.0117
//设置maximumFractionDigits为2
const formatter = Intl.NumberFormat('en-US', { style: 'decimal', maximumFractionDigits: 2 })
formatter.format(num)  // '2,024.01'
```

可以看到最终给出的结果小数位数变成了2位，且会根据四舍五入的方式进行近似。注意，这里的参数也有限制，需要为整数，值为0到20。此外不同style配置下默认值不同，规则和minimumFractionDigits类似。



通过该参数，我们可以将一个数字转化成"整数"，也就是将该值设置成0。



### minimumSignificantDigits
该参数控制得是数字位数，这个听起来似乎有点别扭。通过上面的两个参数，可以知道他们的控制部分分别是整数和小数，而minimumSignificantDigits则以数字总体作为范畴进行处理。

```javascript
const num = 2024.0117
//设置minimumSignificantDigits为12
const formatter = Intl.NumberFormat('en-US', { style: 'decimal', minimumSignificantDigits: 12 })
formatter.format(num)  // '2,024.01170000'
```

当设置该参数时，如果数字本身的位数大于该参数，则不会有变化。如果小于该位数，会末尾（向右）补0，以便数字长度达到规定要求。



### maximumSignificantDigits
该参数和上面的minimumSignificantDigits基本一致，区别在于它控制的是最大的数字位数，这个不太好理解。按照我们举例的数据来说，如果2024.0117，设置该参数为2，那么如何控制"该数字最大有效位数为2位"呢？看例子。

```javascript
const num = 2024.0117
//设置maximumSignificantDigits为2
const formatter = Intl.NumberFormat('en-US', { style: 'decimal', maximumSignificantDigits: 2 })
formatter.format(num)  // ''2,000'
```

可以看到数字被化为了2000，如果是3的话则为2020，5的话则为2024，6的话则为2024.01。也就是说，该参数会从左向右，达到位数后，后一位进行四舍五入，最终给出结果。如果你想要在给出的结果上保留小数位数，同时添加上面控制小数的参数，进行组合使用即可。



这个属性也很好用，特别是一些大数据展示的时候，通常关注数量级数，对末尾精细结果不那么敏感，可以通过该属性有效显示。



### 如何处理冲突
这里的冲突是指如果上述四个属性同时进行了设置，但是相互之间具有冲突的话，如何进行取舍。这里可以通过roundingPriority属性进行控制，roundingPriority包含三个可选值：

1. auto：有效数字结果。
2. morePrecision：精度更高的结果。
3. lessPrecision：精度更低的结果。

需要注意的是roundingPriority属性需要的浏览器版本较高，如果需要使用时请务必关注版本实现。



## 百分比
通常情况下，利用纯数字的处理方式，可以解决90%以上的问题，包括百分比。因为理论上来讲，百分比就是小数进行对应的数位放大之后，添加百分号组成的字符串。但是Intl.NumberFormat仍旧提供了百分比的直接转化与展示，可以帮助你省去中间的一些步骤。

```javascript
const num = 0.45327922
//设置style为percent
const formatter = Intl.NumberFormat('en-US', { style: 'percent' })
formatter.format(num)  // '45%'
```

如图，我们只需要设置style为percent，然后传入指定的小数进行格式化就行，例如上面这个例子，转化为45%。我们同样可以为转化结果设置精确度，这与数字处理并无太大区别。例如我们希望转化后的百分数始终保留两位小数，代码如下：

```javascript
const num = 0.45327922
//设置style为percent
const formatter = Intl.NumberFormat('en-US', { style: 'percent', minimumFractionDigits: 2, maximumFractionDigits: 2 })
formatter.format(num)  // '45.33%'
```

其他配置可根据上面的纯数字部分内容自行调整。



## 货币金额
货币本身是一个与国家相关的属性，所以当我们style设置为currency时，应当始终设置currency属性，其可能得值为ISO 4217标准中的货币代码，可以据此获得参考：[点击这里](https://en.wikipedia.org/wiki/ISO_4217#List_of_ISO_4217_currency_codes)。例如下图给出两个示例，分别以CNY(人民币)和USD(美元)进行数据展示。

```javascript
const num = 2023.456
//设置style为currency
const USDFormatter = Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' });
const CNYFormatter = Intl.NumberFormat('en-US', { style: 'currency', currency: 'CNY' });
USDFormatter.format(num)   // '$2,023.46'
CNYFormatter.format(num)   // 'CN¥2,023.46'
```

可以看到添加了对应的货币符号。



和货币金额有关的另一个属性是currencyDisplay，控制货币显示的格式。像上面金额前面出现的$，CN￥等就是该属性控制的。可选值有以下几个：

1. code：使用的是ISO货币代码。
2. symbol：使用本地化的货币符号，这个是默认值。
3. narrowSymbol：使用更简略的符号，例如是￥而不是CN￥。
4. name：使用本地化名称，例如上述例子中，currency为CNY时，则为2,023.46 Chinese yuan。



## 单位数字
单位数字是指带单位的数据，例如常见的2kg, 3km, 1024bytes等。通过设置style为unit可以实现该类数据的处理。

```javascript
const num = 2023.456
//设置style为unit
const formatter = Intl.NumberFormat('en-US', { style: 'unit', unit: 'kilogram' });
formatter.format(num) // '2,023.456 kg'

```

支持的单位可以在这里查到[点击查看所有单位](https://tc39.es/ecma402/#table-sanctioned-single-unit-identifiers)。



单位的展示格式也可以用unitDisplay来控制，一般指的是完全单位还是缩写。
